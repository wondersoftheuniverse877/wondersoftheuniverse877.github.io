Privacy policy

Studio Uploader. Last updated November 13, 2026.

Studio Uploader is a private tool that the owner of one YouTube channel runs on their own computer to publish and manage that channel's videos. This policy explains what Google user data it accesses and what it does with it. The only account it is used with is the channel owner's.

What it accesses

With the channel owner's permission, Studio Uploader uses the YouTube Data API and the YouTube Analytics API with these permissions:

  • youtube.upload: upload videos to the channel;
  • youtube.force-ssl: manage the channel's videos, thumbnails, captions and playlists, and read the channel's name and ID;
  • yt-analytics.readonly: read the channel's YouTube Analytics reports.

How it uses that data

Only to upload and manage the channel owner's own videos and to read the channel's own performance figures, which help plan future videos. It doesn't access other people's accounts, channels or private information.

Storage

The sign-in token Google issues is stored only on the channel owner's computer, outside any shared or synced folder. Analytics figures the tool reads are saved on that same computer. Studio Uploader has no server: no Google user data is sent anywhere except back to Google's own APIs.

Sharing

Studio Uploader doesn't sell, share or transfer Google user data to anyone. It shows no ads, uses no third-party analytics, and doesn't use Google user data to develop, improve or train AI or machine learning models.

Studio Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

Studio Uploader uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time from the Google Account security settings at security.google.com/settings/security/permissions. When access is revoked, or the tool is retired, the stored token and any stored YouTube data are deleted from the owner's computer within 7 days.
