Studio Uploader

A private publishing tool for one YouTube channel about space and physics at true scale.

What it does

Studio Uploader runs on the channel owner's own computer and signs in with that channel's Google account. It uses the YouTube Data API and the YouTube Analytics API to:

  • upload the channel's finished videos as private, with a scheduled publish time;
  • set each video's thumbnail and English captions, and add videos to the channel's playlists;
  • read the channel's own YouTube Analytics (views, watch time, audience retention) to help plan future videos.

Who uses it

Only the owner of the channel, for that channel. It isn't offered to anyone else and has no sign-up. It never acts on other people's accounts or videos.
